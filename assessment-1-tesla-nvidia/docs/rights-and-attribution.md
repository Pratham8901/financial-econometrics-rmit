# Data rights, attribution and academic integrity

This repository is a **portfolio-style, AI-assisted reconstruction** derived from an individual Financial Econometrics assessment undertaken at RMIT University. The original assessment report and script have been reviewed to identify and document methodological issues; the revised analysis and graphics were prepared as a separate portfolio artefact. Readers should not assume the portfolio code was entirely independently authored, or that the original submission has been replaced or resubmitted.

Excluded from this public-ready package:

- Original submitted university report and R script containing personal identifiers.
- Original price-history CSV extracts and daily Fama–French dataset (kept local under `data/private/`).
- RMIT assignment instructions, course lecture material, instructor files or grading information.

Sources include **Investing.com historical price extracts** and the **Kenneth French Data Library daily three-factor research dataset**. Cite sources when presenting the analysis; obey their licensing and data-use conditions. Neither RMIT, the companies nor data providers endorse this repository.

Historical case study only, not investment advice.
