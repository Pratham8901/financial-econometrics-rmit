# Data rights, authorship and responsible sharing

This case study originates from an **individual RMIT University Financial Econometrics assessment submitted in 2026**. This repository is a **subsequent, AI-assisted portfolio reconstruction**, not the original assessed report or original R code.

The submitted raw extracts were from **Investing.com** and the user also uploaded **NVIDIA and Kenneth French Fama–French CSV/Excel files**. Reproducing provider exports in public may require permissions. No source historical-price files, `FF model` source datasets, original submitted report, workspace-state files, student number or copyrighted assessment material is republished here.

The published aggregate tables are either (a) independently recalculated from the user's data or (b) explicitly marked as numbers transcribed from the original student submission. Employer-facing claims should describe individual work honestly, and should not claim professional trading success or native R reproductions that have not happened.
